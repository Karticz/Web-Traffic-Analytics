# Web-Traffic-Analysis
## Objective
Examine website traffic data to understand user behavior, identify key metrics such as page views, session duration, and drop-off points, and map user journeys to uncover insights that can improve engagement.

## Key Metrics Analyzed
- **Page Views:** Total number of times pages were visited.
- **Session Duration:** Average time spent by users on the website.
- **Drop-off Points:** The specific pages where users exit the website.

## User Journey Mapping
- **Path:** Home -> Products -> Add to Cart -> Checkout 
- **Observation:** A significant drop-off was identified at the Checkout page.

## Insights & Recommendations
- The high drop-off at checkout indicates a need for a simpler, faster payment process.
- Users are spending the most time on the 'Products' page, showing high engagement with the catalog.
